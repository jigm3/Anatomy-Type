# Anatomy Type

Learn anatomy by typing the names of real 3D models: bones, nerves and brain, organs, muscles and blood vessels.
Lessons, three rounds per level (name shown → clue → from memory), clinical questions and spaced review.

Open `index.html` through any web server, or visit the GitHub Pages site. It can be installed to a phone or desktop home screen and works offline after the first visit.
Progress is saved in your own browser.
